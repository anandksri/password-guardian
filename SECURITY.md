# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately rather than opening a public issue.

When reporting a vulnerability, include:

- A clear description of the issue
- Steps to reproduce the behavior
- The affected file, feature, or component
- Security impact and potential abuse scenarios
- Any proof of concept that helps reproduce the issue safely

Do not include real passwords, credentials, tokens, or other sensitive personal data in a report.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing technical details.

## Scope

This policy applies to the code and functionality maintained in this repository.
